# SSH Manager v0.5.0

**SSH Manager is now open source**, under the Apache License 2.0. Download a ready-to-run package for your
system below; there's nothing to build, and the full source code is in this repository.

![SSH Manager](https://github.com/imtiaz9832/ssh-manager/raw/v0.5.0/docs/screenshots/main-light.png)

## Download

| System | File | How to install |
|---|---|---|
| **macOS** 13+ (Apple Silicon) | `ssh-manager-macos-arm64.dmg` | Open it and drag **SSH Manager** to **Applications** |
| **Windows** 10 / 11 (x64) | `ssh-manager-windows-x64-setup.exe` | Run the installer. No admin rights needed |
| **Windows**, portable | `ssh-manager-windows-x64-portable.zip` | Extract anywhere and run `ssh-manager.exe` |
| **Ubuntu / Debian** (x86_64) | `ssh-manager-linux-amd64.deb` | `sudo apt install ./ssh-manager-linux-amd64.deb` |
| **Other Linux** (x86_64) | `ssh-manager-linux-x86_64.tar.gz` | Extract and run `ssh-manager/ssh-manager` |

Each file is also listed with the version in its name. `SHA256SUMS.txt` has checksums for all of them.

### First launch on macOS and Windows

The apps aren't code-signed yet, so the OS warns you the first time:

- **macOS:** if it says the app "can't be opened" or "is damaged", run this once, then open it again:
  ```bash
  xattr -dr com.apple.quarantine "/Applications/SSH Manager.app"
  ```
- **Windows:** if SmartScreen shows "Windows protected your PC", click **More info → Run anyway**.
