# SSH Manager v0.4.1

A small update: every server can now have a **public IP**, shown in its own column next to the address
SSH Manager connects to, and included in search.

![SSH Manager](https://github.com/imtiaz9832/ssh-manager/raw/v0.4.1/docs/screenshots/main-light.png)

## What's new

- **Public IP column**, right after **IP / Host**. Servers without one show a dash.
- **Search by public IP:** type a full or partial address, like `198.51` or `198.51.100.21`, to find the server.
- **Public IP in the details panel and in Add / Edit server.** It's for reference only: SSH Manager still
  connects to **Host / IP**, so servers reached over VPN or through a jump host work as before.
- **Columns fit their content:** each column is sized to its widest entry with even spacing, until you resize
  one yourself. After that, your widths are remembered.
- `ssh-manager list` shows the public IP too.

In the inventory file it's an optional `public_ip` field; existing inventories keep working unchanged. See
[`examples/inventory.example.json`](https://github.com/imtiaz9832/ssh-manager/blob/v0.4.1/examples/inventory.example.json).

## Download

| System | File |
|---|---|
| Ubuntu / Debian (x86_64) | `ssh-manager_0.4.1_amd64.deb` |
| Other Linux (x86_64) | `ssh-manager-0.4.1-linux-x86_64.tar.gz` |
| macOS 13+ (Apple Silicon) | `ssh-manager-0.4.1-macos-arm64.dmg` |
| Windows 10 / 11 (x64) | `ssh-manager-0.4.1-windows-x64-setup.exe` or `…-portable.zip` |

Install steps, compatibility and first-launch notes for macOS and Windows are the same as in
[v0.4.0](https://github.com/imtiaz9832/ssh-manager/releases/tag/v0.4.0).

**Upgrading:** click **Quit** in the running app before installing. An older version that is still open
doesn't know the new field and would drop the public IPs the next time it saves.
