# SSH Manager v0.4.0

**Stop memorising IPs, usernames, keys and jump-host commands.** SSH Manager keeps all your servers in one
searchable list and opens an SSH session in a new terminal with one click.

This is the first release with **ready-to-install packages for Ubuntu, macOS and Windows**. Download the file
for your system below; there's nothing to build.

![SSH Manager](https://github.com/imtiaz9832/ssh-manager/raw/v0.4.0/docs/screenshots/main-light.png)

## Download

| System | File | How to install |
|---|---|---|
| **Ubuntu / Debian** (x86_64) | `ssh-manager_0.4.0_amd64.deb` | `sudo apt install ./ssh-manager_0.4.0_amd64.deb`, then open **SSH Manager** from the app menu or run `ssh-manager` |
| **Other Linux** (x86_64) | `ssh-manager-0.4.0-linux-x86_64.tar.gz` | Extract, then run `ssh-manager-0.4.0/ssh-manager/ssh-manager` |
| **macOS** (Apple Silicon) | `ssh-manager-0.4.0-macos-arm64.dmg` | Open the `.dmg` and drag **SSH Manager** to **Applications** (see the first-launch note below) |
| **Windows 10 / 11** (x64) | `ssh-manager-0.4.0-windows-x64-setup.exe` | Run the installer. No admin rights needed |
| **Windows, portable** | `ssh-manager-0.4.0-windows-x64-portable.zip` | Extract anywhere and run `ssh-manager.exe` |

`SHA256SUMS.txt` lists checksums for every file.

### First launch on macOS and Windows

The app isn't code-signed yet, so the OS warns you the first time:

- **macOS:** if it says the app "can't be opened" or "is damaged", run this once in Terminal, then open it again:
  ```bash
  xattr -dr com.apple.quarantine "/Applications/SSH Manager.app"
  ```
  Or right-click the app, choose **Open**, then **Open** again.
- **Windows:** if SmartScreen shows "Windows protected your PC", click **More info → Run anyway**.

| **Ubuntu** | 22.04, 24.04 and newer | Also Debian 12+ and other glibc 2.35+ distributions (`.tar.gz`) |

**Requirement:** an OpenSSH client (`ssh`). It ships with Ubuntu, macOS and Windows 10/11.

## Features

**Your servers in one place**
- A list with name, hostname, IP, user, group, access type and description; group sidebar and instant search
- A details panel with the key path (warns if the file is missing), jump host and the full `ssh` command
- Add, edit, duplicate and delete servers, or import your existing `~/.ssh/config`

**One-click connect**
- **Connect** (or double-click / Enter) opens a new terminal tab with the session
- Jump hosts built in: no more long `ProxyCommand` lines
- Per-server user, key, port and extra `ssh -o` options, with defaults for everything else

**Know what's reachable**
- Live status dots, and **Check all** with progress and a result summary
- VPN servers are tagged, with a "VPN connected?" hint when they're unreachable
- **Fetch hostname** logs in and records each server's real hostname

**Works the way you do**
- Light, dark or system theme, and a font size that the whole layout scales with
- Resizable panels; the layout is remembered
- Optional background mode: hide the window and bring it back by running `ssh-manager` again
- A plain JSON inventory you can share with your team, plus a generated `ssh_config` so
  `ssh <name>`, `scp` and VS Code Remote-SSH use the same list
- A CLI: `ssh-manager connect | list | command | import | fetch-hostnames`

## What's new in v0.4.0

- **Downloadable packages for Ubuntu, macOS and Windows**, built and published automatically for every release
- **Windows support:** sessions run in Windows Terminal (or a console window) using the built-in OpenSSH, and
  jump hosts work through the generated `ssh_config`
- **App icons** for the Windows installer, macOS app and Linux menus
- A Windows installer that installs per user without admin rights, with a Start-menu entry and an uninstaller

Earlier in v0.3.x: a layout that scales with the font, resizable panels, results for **Check all**, a close
button that quits, dialogs that scroll at large font sizes, and clear errors when a terminal fails to start.

### Known limitations

- The macOS and Windows builds are new. Please report anything that doesn't work.
- macOS builds are for Apple Silicon only, and nothing is code-signed yet (see the first-launch note above).
- On Windows the app is GUI-only; CLI commands such as `ssh-manager list` are for Linux and macOS.
