# Code of conduct

SSH Manager follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and help keep this a welcoming project for
people of every background and experience level. Harassment, insults and personal attacks aren't tolerated.

To report unacceptable behaviour, contact the maintainer, Muhammad Imtiaz
([@imtiaz9832](https://github.com/imtiaz9832)), through a private message or a private security advisory.
Reports are handled confidentially.
